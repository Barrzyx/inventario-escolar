# Diretrizes e Preferências do Usuário

- **Autonomia Total**: O usuário concede permissão total para criar, editar arquivos, refatorar código e executar comandos necessários para concluir as tarefas sem precisar pedir confirmações intermediárias ou permissão prévia.
- **Ação Direta**: Sempre execute diretamente as modificações solicitadas e reporte os resultados de forma clara e objetiva.
